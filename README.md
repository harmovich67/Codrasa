# Codrasa

منصة ويب لتدريس البرمجة. الدرس فيها مش فيديو، هو **جلسة كود حية بتتعاد**: الطالب يوقف الشرح في أي ثانية، يعدّل الكود ويشغّله، ويسأل عن السطر اللي واقف عنده. وفيها كمان لوحة إدارة كاملة للمدرّس.

## التشغيل

```bash
npm install        # مرة واحدة (بيسطّب الـ server والـ client مع بعض)
npm run dev        # API على 4000 + الواجهة على http://localhost:5173
```

افتح `http://localhost:5173`. أول حساب بيتعمل بيبقى **حساب المدرّس**.

مفتاح Gemini تقدر تحطه من **الإعدادات** في الواجهة، أو في `server/.env` (انسخ `server/.env.example`).

للإنتاج: `npm run build` وبعدين `npm start`، والسيرفر بيخدم الواجهة والـ API على نفس البورت.

## المتطلبات
- Node.js 22.13 أو أحدث (بنستخدم `node:sqlite` المدمج، فمفيش أي حاجة native محتاجة تتبني)

## إزاي تدير الطلاب والكورسات
| عايز | تعمله إزاي |
|---|---|
| تفتح كورس لطالب معين | صفحة الكورس ← "افتح الكورس لطالب معين"، أو صفحة الطالب ← "افتح كورس للطالب" |
| تخلي كورس مخفي إلا عن ناس معينة | تعديل الكورس ← **كورس خاص**. مش بيظهر في القائمة لحد ما تفتحه لطالب |
| الطالب يطلب كورس مدفوع | بيدوس "اطلب الاشتراك" ويكتب رقم التحويل. الطلب بيظهر في **طلبات الاشتراك** (وعليه رقم في القائمة الجانبية) |
| تقبل الطلب | "قبول" بيفعّل الكورس، وبيسجّل الدفعة لو سيبت الخيار شغال |
| تسجّل دفعة من غير طلب | **الماليات** ← دفعة جديدة (بتفعّل الكورس تلقائيًا) |
| الطالب يسأل | من جوه الدرس (زرار "اسأل المدرّس"، السؤال بيتثبت على الثانية والسطر) أو من صفحة **أسئلتي** |

## التعلّم بالإتقان: التحديات وخريطة المهارات
- **تحديات داخل الدرس:** من استوديو الدرس ← تبويب **التحديات**، حط تحدي (اختيار من متعدد، أو تحدي كود JavaScript بيتصحح بمقارنة ناتج `console.log`) على أي لحظة في التسجيل. الدرس بيقف عندها ومبيكمّلش لحد ما الطالب يحلّه (أو تخليه اختياري).
- **اقتراحات جاهزة:** الاستوديو بيقترح اللحظات اللي شغّلت فيها الكود وانت بتسجل، وخريطة التوهان فيها زرار «أضف تحدي هنا» مع نصيحة عملية («أعد شرح 08:20…»).
- **خريطة مهارات الطالب:** كل تحدي مربوط بمهارة. صفحة **خريطة مهاراتي** بتوريه اللي أتقنه واللي لسه بيتمرن عليه، وخطوته الجاية.
- **مساعد بمستويات:** تلميح ← أسئلة توجّهه ← شرح الغلطة ← الحل (بيتفتح بعد محاولتين). الإجابة الصحيحة مبتتبعتش للمتصفح أبدًا، والتصحيح كله على السيرفر.
- تعديل نص تحدي أو إجابته بيصفّر تقدم الطلاب عليه (لأنه بقى نسخة جديدة)، والطالب اللي كان مكمّل الدرس وفيه تحدي إجباري جديد بيرجع "غير مكتمل".

## المحرر
- **الإكمال التلقائي:** الاقتراحات بتظهر فورًا وانت بتكتب في كل اللغات.
- **HTML:** اكتب `!` أو `html5` واضغط Tab فيتبني هيكل الصفحة كله. وEmmet شغال (`ul>li*3` ثم Tab)، ووسم الإغلاق (`</div>`) بيتكتب لوحده.
- **Snippets:** `log` `fn` `for` `fetch` في JavaScript، و`def` `forr` `main` في Python، وكمان Java وC++ وC# وPHP وSQL وCSS.
- **ألوان الكود:** كل لغة ليها ثيم ألوان مخصوص (HTML برتقالي، CSS أزرق، JavaScript أصفر/بنفسجي، Python ...). تعريفها في `client/src/lib/editorSetup.js`.
- **تشغيل الكود:** Python بيشتغل جوه المتصفح بـ Pyodide (أول مرة بينزّل حوالي 10 ثواني، وبعدها فوري، وبيتقتل بعد 5 ثواني لو فيه حلقة لا نهائية، و`input()` مش مدعوم). JavaScript بيشتغل جوه المتصفح. الكود العادي في Worker معزول بيتقتل بعد 4 ثواني لو فيه حلقة لا نهائية. ولو الكود بيستخدم `alert` أو `prompt` أو `confirm` أو `document` بيشتغل تلقائيًا في iframe معزول فيه الدوال دي.

## التقنيات
- **الواجهة:** React 19 (JSX بدون TypeScript) + Vite + Tailwind 4 + Monaco Editor + Zustand
- **السيرفر:** Express 5 + SQLite (`node:sqlite`) + JWT
- **الذكاء الاصطناعي:** `@google/genai`. الموديل السريع `gemini-3.5-flash-lite` للمحادثة، والأذكى `gemini-3.6-flash` للملخصات والاختبارات والردود. الاتنين قابلين للتغيير من الإعدادات.

## البيانات
كل حاجة في `server/data/`: قاعدة البيانات `codrasa.db` وملفات الصوت `uploads/audio/`. انسخ الفولدر ده وانت عندك نسخة احتياطية كاملة. التحديثات اللي بتضيف أعمدة جديدة بتتطبق على قاعدتك القديمة تلقائيًا عند تشغيل السيرفر.

## هيكل المشروع
```
server/src/
  index.js            تشغيل Express والمسارات
  db.js               الجداول والـ helpers
  auth.js / access.js JWT والصلاحيات
  checkpoints.js      التحقق من التحديات وتصحيحها وتقدم الطالب
  ai.js               عميل Gemini والحد اليومي للطلاب
  routes/             auth, courses, lessons, students, payments, questions, requests, forks, ai, settings, dashboard, skills
client/src/
  lib/recording.js    مسجّل الدرس + إعادة بناء الكود عند أي لحظة
  lib/usePlayback.js  ساعة التشغيل (مربوطة بالصوت)
  lib/runner.js       تشغيل JavaScript (Worker أو iframe معزول)
  lib/editorSetup.js  ثيمات الألوان والـ snippets وEmmet
  pages/LessonPlayer  مشغّل الدرس للطالب
  pages/teacher/      الاستوديو ولوحة الإدارة (والطلبات)
  pages/student/      صفحات الطالب
```
